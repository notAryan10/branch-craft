# 🌿 BranchCraft

**BranchCraft** is a simple and interactive React-based mind-mapping tool built with [React Flow](https://reactflow.dev/). It allows you to visually map out ideas by creating branches, renaming them, and deleting nodes in a fluid, intuitive interface.

## 🚀 Features

- 🧠 Start with a main topic node
- ➕ Add branches to selected nodes
- ✏️ Rename nodes
- 🗑️ Delete nodes (except the main topic)
- 🎯 Click to select nodes and edit them
- 🌐 Smooth connections between branches
- ⚙️ Drag and reposition nodes
- 🎨 Clean UI with background grid and toolbar

## 📦 Built With

- [React](https://reactjs.org/)
- [React Flow](https://reactflow.dev/)
- JavaScript
- CSS Modules
